# Sample statements

Synthetic exports in the exact formats the parsers expect. Generated by
`node scripts/make-samples.mjs`; do not edit by hand.

- `fio-sample.csv`, `revolut-sample.csv`, `airbank-sample.pdf`: small hand-written fixtures that
  hit every parser branch. The parser tests and snapshots are built on them.
- `demo-fio-year.csv`: a generated year of everyday FIO spending (March 2023 to February 2024),
  so the demo shows a full year. Not a parser fixture.

All four are loaded by the "Try with sample data" button and by the GitHub Pages demo.

Everything in them is fictional. Account numbers come from a reserved fake range:

| Account | Role in the samples |
|---|---|
| `2900000001/2010` | FIO main account (the statement's own account) |
| `2900000002/2010` | FIO savings account (own, transfers are not spending) |
| `1000000001/3030` | Air Bank account |
| `3000000001/2010` | broker (investment account) |
| `4000000001/0100` | landlord (category by account: Housing & utilities) |
| `4000000002/0800` | utility company (category by account) |
| `4000000003/0300` | insurer (category by account: Insurance) |
| `5500000001/0100` | employer (salary) |
| `5500000002/0300` | a friend |

`tests/fixtures/rules.json` lists the same accounts, so the samples classify fully under the test
rules.
